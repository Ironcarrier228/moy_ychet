## Мой учёт 0.9.4

- **Фото показаний прямо в чате Telegram-бота:** бот принимает фотографию счётчика, распознаёт цифры и отвечает готовым показанием, которое сразу попадает в историю.
- **Пустой экспорт больше не молчит:** если по выбранному абоненту и периоду показаний нет, приложение объясняет причину вместо создания пустого файла.
- **Ошибки экспорта записываются в журнал операций** — их теперь видно и диагностируется.
- Приветствие бота приглашает присылать фото; распознанные показания подтверждаются кнопками.

**Переход с 0.9.3:** скачайте `moi-uchet.apk` и установите поверх старого приложения, не удаляя его. Подпись — прежний сертификат (`5f5263ea…`), package `kz.meter`, versionCode 13. Схема базы данных не изменена, данные сохраняются.

Перед установкой можно экспортировать Excel. Фото и настройки экспортом не покрываются.

Проверены: полная компиляция без ошибок, подпись APK (v2/v3), метаданные, 27 проверок контракта обновлений, тесты Telegram-бота (включая сценарии фото), тесты валидации и распознавания.

Скачивайте **moi-uchet.apk**, а не автоматически созданные GitHub ссылки «Source code». Файл `update.json` — служебные метаданные для проверки обновлений.
