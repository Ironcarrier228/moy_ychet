## Мой учёт 0.9.3

- Новый раздел **Ещё → Обновления**.
- Проверка стабильных GitHub Releases при открытии приложения и вручную.
- Сообщение «Доступно обновление», описание версии и загрузка готового APK с прогрессом.
- Проверка SHA-256, версии, пакета и сертификата перед предложением установки.
- Установка через системное подтверждение Android. Исходники и ключ подписи в релиз не загружаются.

**Первый переход с 0.9.2:** скачайте `moi-uchet.apk` и установите поверх старого приложения, не удаляя его. Подпись соответствует прежнему сертификату, package `kz.meter`, versionCode 12. Схема базы данных не изменена.

Перед установкой экспортируйте Excel. Это не полная резервная копия фотографий и настроек. На реальном телефоне установка ещё не проверена; при ошибке не удаляйте старое приложение.

Проверены: сборка, подпись APK (v2/v3), метаданные, 27 проверок контракта обновлений, 7 сценариев интерфейса с mock Native bridge, тесты валидации/приборов/распознавания чисел.

Скачивайте **moi-uchet.apk**, а не автоматически созданные GitHub ссылки «Source code». Файл `update.json` — служебные метаданные для проверки обновлений.
