## Мой учёт 0.9.5

- **Пуш-напоминание о показаниях:** Android-приложение напоминает в уведомлениях, что пора снять показания — дата берётся из периодов абонента, окно часов настраивается в настройках.
- **Фото-показания теперь проходят черновик:** сообщение с фото сначала становится черновиком — управляющий видит уведомление «Новое фото-показание на проверку», открывает страницу «Фото на проверку», сверяет распознанные цифры с фото и подписью и жмёт «Подтвердить» или «Отклонить». Подтверждённое сразу попадает в историю и Excel.
- **Показание можно исправить при подтверждении:** если OCR ошибся, вводится правильное число прямо на странице проверки.
- Защита от двойной обработки: один и тот же черновик нельзя подтвердить дважды.

**Переход с 0.9.4:** скачайте `moi-uchet.apk` и установите поверх старого приложения, не удаляя его. Подпись — прежний сертификат (`5f5263ea…`), package `kz.meter`, versionCode 14. Схема базы данных не изменена, данные сохраняются.

Перед установкой можно экспортировать Excel. Фото и настройки экспортом не покрываются.

Проверены: полная компиляция без ошибок, подпись APK (v2/v3), метаданные, 27 проверок контракта обновлений, тесты пуш-напоминаний, тесты черновиков, тесты Telegram-бота (включая сценарии фото), тесты валидации и распознавания.

Скачивайте **moi-uchet.apk**, а не автоматически созданные GitHub ссылки «Source code». Файл `update.json` — служебные метаданные для проверки обновлений.
