# Мой учёт — Android

Публичный канал готовых приложений. Исходники и ключи подписи сюда не публикуются.

## Установка и обновления

Готовые версии размещаются в [Releases](https://github.com/Ironcarrier228/moy_ychet/releases).
Скачивайте **`moi-uchet.apk`**, а не «Source code (zip / tar.gz)».
На момент подготовки этой ветки новый подписанный APK ещё не опубликован.

В версии **0.9.3** подготовлена система обновлений:

- Проверка последнего стабильного GitHub Release при открытии приложения, не чаще раза в 6 часов.
- Ручная проверка: **Ещё → Обновления → Проверить обновления**.
- Сообщение **«Доступно обновление»**, версия, описание и размер загрузки.
- Скачивание APK по кнопке с отображением прогресса.
- Проверки размера, SHA-256, имени пакета, версии и сертификата подписи.
- Установка через системное окно Android, только с вашего подтверждения.

Проверка не работает в фоне при закрытом приложении. Для загрузки оставьте приложение открытым.
При обрыве загрузку можно повторить. Неудачная проверка не мешает локальному учёту.

### Первый переход с 0.9.2

В старом приложении этой функции нет. **Первый APK с системой обновлений необходимо установить вручную**,
поверх старой версии, без удаления. APK должен быть подписан прежним ключом.
Перед обновлением экспортируйте Excel. Удаление приложения удаляет его базу, фотографии и настройки;
Excel не является полной резервной копией всех данных приложения.

Если Android запросит разрешение на установку из этого источника, разрешите его для «Мой учёт»,
вернитесь в приложение и повторно нажмите **«Установить обновление»**.

## Для владельца

На один стабильный релиз загружаются только:

- `moi-uchet.apk` — подписанное приложение;
- `update.json` — версия, размер и контрольная сумма APK (не исходники и не секреты).

Изменение файлов репозитория само по себе не является обновлением приложения.
Нужен новый опубликованный стабильный Release с увеличенным `versionCode` и обоими файлами.
Черновики и предварительные релизы телефоном не предлагаются.
Архивы исходников, ключи, пароли, базы и фотографии пользователей публиковать нельзя.

**Важное ограничение:** удаление старого архива из текущего дерева не стирает его из истории Git.
См. [PRIVACY.md](PRIVACY.md). Пока история не очищена, считать старые исходники скрытыми нельзя.
